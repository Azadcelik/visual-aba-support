Visual ABA Practice

Updated August 20, 2026

Private data stays on the device

Learner names, custom activities, session results, progress, reports, and custom media are stored locally on the user's device. Visual ABA Practice does not require an account and does not upload this private content to Visual ABA Practice or Supabase.

Public learning library

Visual ABA Practice uses Supabase to deliver built-in public categories, pictures, videos, sequences, and phoneme audio. These requests may provide Supabase with ordinary network information such as an IP address, device browser information, requested file, and request time for service operation and security.

No tracking or advertising

Visual ABA Practice does not include advertising, behavioral analytics, third-party tracking, or a crash-reporting service. It does not access contacts, location, camera, or microphone.

Device-owner authentication

If a manager forgets the local Manager PIN, Visual ABA Practice can ask the operating system to verify the device owner using Face ID, Touch ID, or the device passcode. Visual ABA Practice receives only whether verification succeeded and does not receive or store biometric data or the device passcode.

User-selected files and exports

Pictures or videos selected for custom activities remain in Visual ABA Practice's private local storage. A report leaves Visual ABA Practice's protected storage only when the user intentionally exports it; the selected destination then controls that exported copy.

Deletion and retention

Local information remains until the user deletes a learner, deletes individual content, or removes Visual ABA Practice. Deleting a learner removes that learner's sessions, progress, saved programs, custom content, and Choice Board from that device.

Educational use

Visual ABA Practice is an educational practice tool. It does not diagnose, treat, or replace individualized advice from a qualified professional.

Support

Questions can be submitted through the Visual ABA Practice support page.
